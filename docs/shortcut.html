バックグラウンド自動処理の作り方

「ショートカット」アプリに、スクショの解析からメモ作成までを全部任せます。夜中などに自動で実行されるので、アプリを開いておく必要はありません。

できあがる仕組み
  1. 決まった時刻にショートカットが自動で動く
  2. 「どこまで処理したか」の日時をファイルから読み、それより新しいスクショを古い順に 20 枚取り出す
  3. 1枚ずつ Gemini に送り、「Q. 問題文 / A. 答え」を受け取る
  4. クイズならメモアプリに 1枚 = 1メモで保存（クイズ以外は何もしない）
  5. 1枚終わるごとに、その撮影日時をファイルに記録（次回はその続きから）
  6. エラー（回数制限など）が出たらそこで止まり、次回同じ所からやり直す
※ iPhone のショートカットには「写真をアルバムに入れる」機能がないため、処理済みの印は日時で管理します。

1. 最初に1回だけ：記録ファイルを作る

ショートカットアプリ → ＋ → 名前 スクショ記録リセット で、次の2つだけのショートカットを作って 1回実行 します。

テキスト（2000/01/01 00:00:00）
ファイルを保存
  1. テキスト に下の日時を貼り付け
  2. ファイルを保存 の ＞ を開き、保存先を尋ねる：オフ、保存先フォルダ：Shortcuts、サブパス：下の名前、上書き：オン
  3. ▶ で1回実行（iCloud Drive の Shortcuts フォルダにファイルができます）
2000/01/01 00:00:00
スクショ最終日時.txt

最初からやり直したいときも、これを実行すれば記録が最初に戻ります。

2. メインのショートカット

名前 スクショ自動解析。完成形はこうなります（字下げは「繰り返し」「If」の中）。

ファイルを取得（Shortcuts/スクショ最終日時.txt）
入力から日付を取得
写真を検索（スクリーンショット・作成日が[日付]より後・古い順・20枚）
各項目を繰り返す
    繰り返し項目 を JPEG に変換
    base64でエンコード（行区切り：なし）
    テキスト（送信内容）
    URLの内容を取得（Gemini）
    辞書の値を取得
    テキスト（辞書の値）
    If テキスト が Q. を含む
        メモを作成（辞書の値）
    その他の場合
        If テキスト が なし を含まない
            このショートカットを停止
        If文の終了
    If文の終了
    日付を調整（繰り返し項目の作成日 に 1秒 を加算）
    日付をフォーマット（カスタム）
    ファイルを保存（上書き）

繰り返しの終了

2-1. ファイルを取得 Get File

「ファイルを取得」で検索（「フォルダからファイルを取得」の場合もあり）。フォルダ：Shortcuts、パス：スクショ最終日時.txt

スクショ最終日時.txt

2-2. 入力から日付を取得 Get Dates from Input

「日付を取得」で検索。入力は「ファイル」（自動で入っていればOK）。

2-3. 写真を検索 Find Photos

  1. フィルタ：スクリーンショット（そのまま）
  2. フィルタ：作成日 → が次より後 → 値に変数 日付（2-2 の結果）を選ぶ
  3. 並び順：作成日・古い順、制限：オン・20（試すときは 2）

2-4. 繰り返しの中（解析部分）

JPEGに変換 → base64（行区切りなし）→ テキスト（下の文。BASE64 の所に変数）→ URLの内容を取得 → 辞書の値を取得 → テキスト（中身は 辞書の値）。

URLの内容を取得：URL は下、方法 POST、ヘッダ x-goog-api-key＝APIキー と Content-Type＝application/json、本文を要求：ファイル＝テキスト

x-goog-api-key
Content-Type
application/json

辞書の値を取得：キー

candidates.1.content.parts.1.text
APIキーはショートカットの中（あなたのiPhone）にだけ保存されます。このショートカットを他人に共有しないでください。

2-5. If文（メモ作成とエラー時の停止）

  1. If：テキスト が 次を含む Q. → 中に メモを作成（内容：辞書の値、＞で「作成画面を表示」オフ）
  2. 「その他の場合」の中に、もう1つ If：テキスト が 次を含まない なし → 中に このショートカットを停止（「停止」で検索）
Q.
なし

「Q.」も「なし」も無い ＝ エラー（回数制限など）。その場で止まるので、記録は進まず、次回同じスクショからやり直します。

2-6. 処理した日時を記録する

  1. 日付を調整：1 秒を 加算、日付の欄は 繰り返し項目 をタップ →「種類」で 作成日 を選ぶ
  2. 日付をフォーマット：日付の形式 カスタム、書式に下の文字（入力は「調整済みの日付」）
  3. ファイルを保存：入力は「フォーマット済みの日付」、＞で 保存先を尋ねる：オフ、フォルダ Shortcuts、サブパス スクショ最終日時.txt、上書き：オン
  4. 待機：7 秒
yyyy/MM/dd HH:mm:ss

1秒足すのは、同じスクショを次回もう一度処理しないためです。

3. まず手動で試す

  1. 写真を検索の制限を 2 にして ▶
  2. 許可を聞かれたら 常に許可（写真・ファイル・generativelanguage.googleapis.com・メモ）
  3. メモができて、もう一度 ▶ したときに次の2枚に進んでいれば成功。制限を 20 に戻す

4. 自動実行の設定（オートメーション）

  1. ショートカットアプリ下の オートメーション → ＋
  2. 時刻 → 例 午前 1:00・毎日 → すぐに実行
  3. 次へ → スクショ自動解析 を選んで完了
  4. 午前 1:30、2:00、2:30 … と何個か作ると、1晩で「20枚 × 個数」を処理（多くても 20個まで）
自動実行が長すぎると iOS に途中で止められることがあります。止められても記録は1枚ごとに保存されているので、次回は続きから処理されます。

5. 処理済みスクショの削除（ときどき手動）

写真の削除は iPhone の仕様で必ず確認が出ます。クイズ以外の大事なスクショを消さないよう、一覧で確認してから消すショートカットにします。

ファイルを取得（Shortcuts/スクショ最終日時.txt）
入力から日付を取得
写真を検索（スクリーンショット・作成日が[日付]より前）
リストから選択（複数選択：オン）
写真を削除
  1. 名前は 処理済みスクショを削除 など
  2. 「リストから選択」で一覧が出るので、すべて選択 → 残したいスクショだけタップして外す → 完了
  3. 「○枚削除しますか」→ 削除。最後に写真アプリの 最近削除した項目 を空にすると容量が空きます
