バックグラウンド自動処理の作り方

「ショートカット」アプリに、スクショの解析からメモ作成までを全部任せます。夜中などに自動で実行されるので、アプリを開いておく必要はありません。

できあがる仕組み
  1. 決まった時刻にショートカットが自動で動く
  2. まだ処理していないスクショを古い順に 20 枚取り出す
  3. 1枚ずつ Gemini に送り、「Q. 問題文 / A. 答え」を受け取る
  4. メモアプリに 1枚 = 1メモで保存
  5. 処理したスクショは「処理済み」アルバムへ（クイズ以外は「クイズ以外」へ）
削除だけは iPhone の仕様で必ず確認が出るため、ときどき手動で行います（最後の章）。

1. 準備（写真アプリ）

  1. 写真アプリ → アルバム → 左上の ＋ → 新規アルバム → 名前 処理済み
  2. 同じように、もう1つ クイズ以外 というアルバムを作る
処理済み
クイズ以外

2. ショートカットを作る

ショートカットアプリ → 右上の ＋ → 名前を スクショ自動処理 にします。
下の「アクションを検索」で次のアクションを上から順に追加します。（名前が見つからないときは 灰色の英語名 でも検索できます）

各項目を繰り返す
    画像を変換（JPEG）
    Base64エンコード（改行：なし）
    テキスト（送信内容）
    URLの内容を取得（Gemini）
    辞書の値を取得
    if 辞書の値 が「Q.」を含む

2-1. 写真を検索 Find Photos

  1. 「フィルタを追加」を押し、条件を スクリーンショットである にする Is a Screenshot
  2. もう一度「フィルタを追加」 → アルバム → 次ではない → 処理済み
  3. さらに「フィルタを追加」 → アルバム → 次ではない → クイズ以外
  4. 並べ替え：作成日、順序：古い順
  5. 「制限」をオンにして 20 枚

2-2. 各項目を繰り返す Repeat with Each

対象が「写真」になっていればOK。以降のアクションは、すべて「繰り返す」と「繰り返しの終了」のあいだに入れます。

2-3. 画像を変換 Convert Image

「繰り返し項目」を JPEG に変換（品質はそのままでOK）。送るデータが軽くなります。

2-4. Base64エンコード Base64 Encode

  1. 対象が「変換された画像」になっていることを確認
  2. 右の ＞ を開き、改行 を なし にする（重要：ここを忘れると必ず失敗します）

2-5. テキスト Text

  1. 下の文をコピーして、テキストの欄に貼り付ける
  2. 文の中の BASE64 という文字だけを消し、その位置で、キーボードの上の候補から Base64エンコード済み の変数を入れる

2-6. URLの内容を取得 Get Contents of URL

  1. URL の欄に下のアドレスを貼り付け
  2. 右の ＞ を開き、方法 を POST にする
  3. ヘッダ を2つ追加する
    • キー x-goog-api-key ／ 値：あなたの Gemini APIキー
    • キー Content-Type ／ 値 application/json
  4. 本文を要求 を ファイル にして、ファイルに 2-5 の テキスト 変数を選ぶ
x-goog-api-key
Content-Type
application/json
APIキーはショートカットの中（あなたのiPhone）にだけ保存されます。このショートカットを他人に共有しないでください。

2-7. 辞書の値を取得 Get Dictionary Value

「値」を取得、キーに下の文字を貼り付け、辞書は「URLの内容」。

candidates.1.content.parts.1.text

2-8. if文 If

  1. 条件：辞書の値 が 次を含む Q.
  2. 「if文」と「その他の場合」のあいだに次の2つを入れる
    • メモを作成：本文に 辞書の値。右の ＞ を開き、「作成画面を表示」をオフ（オンだと自動実行で止まります）。フォルダはお好みで
    • アルバムに追加 Add to Album：繰り返し項目 を 処理済み に追加
  3. 「その他の場合」と「終了」のあいだに、もう1つ if文 を入れる
    • 条件：辞書の値 が 次を含む なし
    • 中に アルバムに追加：繰り返し項目 を クイズ以外 に追加
Q.
なし

エラー（回数制限など）のときはどちらにも当てはまらないので、アルバムに入らず次回もう一度処理されます。

2-9. 待機 Wait

一番外側の「終了」のあと、「繰り返しの終了」の前に入れて 7 秒。無料枠の「1分あたりの回数制限」を超えないためです。

3. まず手動で試す

  1. 写真を検索の「制限」を一時的に 2 にして、右下の ▶ で実行
  2. 途中で「写真へのアクセス」「generativelanguage.googleapis.com への接続」「メモ」の許可を聞かれたら 常に許可
  3. メモアプリに 2件できて、写真の「処理済み」アルバムに 2枚入っていれば成功。制限を 20 に戻す
うまくいかないときは、各アクションの下に結果が表示されます。その画面のスクショを送ってもらえれば直し方を案内します（APIキーが写らないように注意）。

4. 自動実行の設定（オートメーション）

  1. ショートカットアプリ下の オートメーション → ＋（または「新規オートメーション」）
  2. 時刻 を選び、例えば 午前 1:00・毎日 にする
  3. すぐに実行 を選び、「実行時に通知」はお好みで
  4. 次へ → スクショ自動処理 を選んで完了
  5. 同じように 午前 1:30、2:00、2:30 … と何個か作ると、1晩で「20枚 × 個数」を処理できます

目安：1回 20枚（約3分）。1日の無料上限（約500枚）を超えないよう、オートメーションは 多くても 20個 までにしてください。iPhone を充電しながら寝るのがおすすめです。

自動実行が長すぎると iOS に途中で止められることがあります。まずは 20枚で数日試し、問題なければ 30〜40枚に増やしてください。止められても、処理済みのものはアルバムに入っているので、次回は続きから処理されます。

5. 処理済みスクショの削除（ときどき手動）

iPhone の仕様で、写真の削除は必ず確認が必要です。もう1つ短いショートカットを作っておくと、ワンタップで済みます。

写真を検索（アルバム が 処理済み、制限なし）
写真を削除
  1. 名前は 処理済みを削除 など
  2. 実行すると「○枚削除しますか」と出るので 削除
  3. 最後に写真アプリの 最近削除した項目 を空にすると容量が空きます

メモアプリに保存されたことを確認してから削除してください。
