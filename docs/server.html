解析サーバーの作り方

自分の Google アカウントに無料の「解析サーバー」（Google Apps Script）を作ります。スクショを送ったあとアプリを閉じても、Google のサーバーが解析を続けます。最初に1回だけ、約10分の作業です。

できあがる仕組み
  1. アプリでスクショを選んで送信 → 送り終わるまで（数分）だけ開いておく
  2. アプリを閉じる。Google のサーバーが1分ごとに Gemini で解析（1分に約10枚）
  3. アプリを開くと結果が届くので「メモアプリに一括保存」を1回押す
1日の無料枠の上限に達したら、サーバーが夕方（16〜17時ごろ）まで自動で休み、そのあと続きを解析します。
この作業は画面が広いほうが楽です。iPhone の場合は Safari で開き、アドレスバーの「ぁあ」→「デスクトップ用Webサイトを表示」にしてください。パソコンがあればパソコンでもOK（同じ Google アカウントで）。

1. コードをコピー

スクショメモの ⚙ 設定 →「バックグラウンド解析」の ① サーバー用コードをコピー を押します。（このページの下のボタンでもコピーできます）

サーバー用コード（約300行）

2. Apps Script に貼り付けて保存

  1. script.google.com を開き、Google アカウントでログイン → 新しいプロジェクト
  2. 最初から入っている function myFunction() { … } を全部消して、コピーしたコードを貼り付け
  3. 左上の「無題のプロジェクト」を スクショメモ などに変更（任意）
  4. 上の 💾（保存）を押す

3. 許可する（setup を実行）

  1. 上のツールバーの関数の選択欄で setup を選び、▷ 実行
  2. 「承認が必要です」→ 権限を確認 → 自分のアカウントを選ぶ
  3. 「このアプリは Google で確認されていません」と出たら → 詳細 → （プロジェクト名）（安全ではないページ）に移動 → 許可
    自分で作った自分専用のプログラムなので、この表示が出るのは正常です。Google ドライブ（解析待ちの保存）・外部への接続（Gemini）の許可を求められます。
  4. 下の「実行ログ」に「準備ができました」と出ればOK

4. ウェブアプリとして公開（デプロイ）

  1. 右上の デプロイ → 新しいデプロイ
  2. 「種類の選択」の ⚙ → ウェブアプリ
  3. 次のユーザーとして実行：自分、アクセスできるユーザー：全員 → デプロイ
  4. 表示された ウェブアプリの URL（https://script.google.com/macros/s/…/exec）を コピー

「全員」にしても、アプリが自動で作った合言葉を知らない人は使えません。

5. アプリに登録

  1. スクショメモの ⚙ 設定 → ② サーバーの URL に貼り付け
  2. ③ 接続テスト → 「✓ 接続できました」と出たら 保存

これで完了です。以後、スクショを送るとサーバー経由で解析されます。（URL を空にして保存すると、元の「画面の中で解析」に戻ります）

困ったとき

  • 「応答がウェブページでした」：デプロイの「アクセスできるユーザー」が「全員」になっているか確認
  • 「合言葉が一致しません」：別の端末・ブラウザで先に接続しています。Apps Script の ⚙ プロジェクトの設定 → スクリプト プロパティの TOKEN を削除して、もう一度接続テスト
  • 解析が進まない：Apps Script の左の ⏰（トリガー）に processQueue があるか確認。なければもう一度 setup を実行
  • 受け取ったはずの結果が消えた：⚙ の「消えた結果をサーバーから復元（30日以内）」を押す（サーバーのコードが版 4 以降であること）
  • コードを貼り直したときは、デプロイ → デプロイを管理 → ✎ → バージョン：新バージョン → デプロイ（URL は変わりません）
